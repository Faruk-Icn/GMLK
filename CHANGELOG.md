# Changelog

## v0.1.1

- Added a coin counter demonstration GIF to the README.
- Documented common installation, Rojo, example, and webhook setup problems.
- Added a security policy with private vulnerability reporting guidance.
- Added a contribution guide with setup checks and pull request guidance.
- Clarified that remote rate limits are per player and per limiter instance.

## v0.1.0

First tagged release of GMLK.

- One client and one server bootstrap with an `Init` then `Start` module lifecycle.
- Shared number, time, math, table, signal, cleanup, state, pooling, timer, random, tween, and attribute utilities.
- Server remote rate limiting and argument validation helpers.
- Optional server webhook tracker.
- Runnable coin counter example, quick start guide, and automated Luau checks.
